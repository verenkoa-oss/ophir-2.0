## Часть 1 — Что тебе понадобится (до начала установки)

### Оборудование
- Компьютер / Raspberry Pi с Linux (Ubuntu 20.04+ / Debian 11+)
- RTL-SDR USB-донгл (для приёма реальных сигналов)
- Интернет-соединение для установки пакетов

### Программное обеспечение
- Python 3.8 или новее
- pip3 (менеджер пакетов Python)
- git
- dump1090 или dump1090-mutability (**только basic/mobile режим**)
- Ollama (для AI-анализа)

> ❓ **Что такое dump1090?**  
> dump1090 — это программа, которая читает сигналы ADS-B с RTL-SDR донгла  
> и передаёт данные об авиарейсах на порт 30001 (TCP).  
> Система OPHIR подключается именно к этому порту.  
> **Важно:** используется только базовая (`basic`) или мобильная (`mobile`) версия.  
> Версия `dump1090-fa` (FlightAware) — **не поддерживается**.

> ❓ **Что такое Ollama?**  
> Ollama — программа для запуска AI-моделей прямо на твоём компьютере, без интернета.  
> OPHIR использует модель `mistral:latest` через Ollama для анализа аномалий.

## Часть 2 — Очистка старой версии

Если на машине уже была установлена предыдущая версия OPHIR — нужно её убрать.

### Шаг 1 — Остановить все процессы

```bash
# Найти и остановить uvicorn / run.py
pkill -f "uvicorn" 2>/dev/null || true
pkill -f "python3 run.py"  2>/dev/null || true

# Найти и остановить dump1090
pkill -x dump1090            2>/dev/null || true
pkill -x dump1090-mutability 2>/dev/null || true

# Проверить — процессов быть не должно
ps aux | grep -E "uvicorn|dump1090|run\.py" | grep -v grep
```

> ✅ Если вывод пустой — все процессы остановлены.

### Шаг 2 — Удалить старую папку (если нужно переустановить с нуля)

```bash
# ВНИМАНИЕ: убедись, что папка ophir-2.0 не нужна для восстановления данных!
rm -rf ~/ophir-2.0
```

## Часть 4 — Установка dump1090 (basic/mobile)

> ⚠️ **Внимание:** используй только `dump1090` или `dump1090-mutability`.  
> Устанавливать `dump1090-fa` **не нужно** — он не используется в системе.

### Шаг 6 — Установить dump1090-mutability (рекомендуется)

```bash
sudo apt-get install -y dump1090-mutability
```

**Или** — установить стандартный dump1090:

```bash
sudo apt-get install -y dump1090
```

### Шаг 7 — Проверить установку

```bash
which dump1090 || which dump1090-mutability
```

> ✅ Должен вывести путь: `/usr/bin/dump1090` или аналогичный.

### Шаг 8 — Подключить RTL-SDR донгл

1. Вставь RTL-SDR USB-донгл в USB-порт
2. Проверь, что система его видит:

```bash
lsusb | grep -i "RTL\|Realtek\|DVB"
```

> ✅ Должна появиться строка с RTL2838 или аналогичным чипом.  
> ❌ Если не видно — попробуй другой USB-порт или перезагрузись.

## Часть 5 — Установка Ollama и AI-модели

> ❓ **Зачем нужен Ollama?**  
> Ollama запускает AI-модель (Mistral) локально на твоей машине.  
> Это позволяет OPHIR анализировать аномалии без отправки данных в интернет.  
> Если Ollama не запущен — система работает, но без AI-анализа.

### Шаг 9 — Установить Ollama

```bash
curl -fsSL https://ollama.com/install.sh | sh
```

> ⏳ Загрузка и установка — несколько минут.

### Шаг 10 — Запустить сервер Ollama

```bash
ollama serve &
```

> Команда запускает Ollama в фоне. Через пару секунд он готов.

### Шаг 11 — Загрузить модель Mistral

```bash
ollama pull mistral:latest
```

> ⏳ Загрузка модели — от 5 до 20 минут (зависит от скорости интернета).  
> Модель весит ~4 ГБ. Загружается один раз, потом работает офлайн.

### Шаг 12 — Проверить Ollama

```bash
curl -s http://localhost:11434/api/tags | python3 -m json.tool
```

> ✅ Должен вывести JSON со списком моделей, включая `mistral:latest`.  
> ❌ Если ошибка — убедись что Ollama запущен (шаг 10), подожди 10-20 секунд и повтори.

> ✅ Должны быть видны: `main.py`, `run.py`, `start.sh`, `config.py`, `requirements.txt`,

```bash

```

```bash

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

> ✅ Должен вывести: `✅ Все зависимости установлены`

### Шаг 17 — Запустить dump1090 (в отдельном терминале)

Открой новую вкладку / окно терминала и выполни:

```bash

```bash
dump1090-mutability --raw --net --quiet

В основном терминале (из папки `ophir-2.0`):

```bash

**Или через bash-стартер:**

```bash
bash start.sh
```

> ✅ Успешный запуск — ты увидишь сообщения вида:

> INFO - ✅ Application started successfully
> INFO - 🌐 Dashboard: http://0.0.0.0:8080

## Часть 9 — Что делать при ошибках

### ❌ Ошибка: `Address already in use` (порт 8080 занят)

```bash
# Найти и убить процесс на порту 8080
sudo fuser -k 8080/tcp
# Затем снова запустить
python3 run.py
```

### ❌ Ошибка: `ModuleNotFoundError: No module named 'fastapi'`

```bash
pip3 install -r requirements.txt
```

### ❌ Ошибка: `Cannot connect to dump1090`

```bash
# Проверить, что dump1090 запущен
ps aux | grep dump1090 | grep -v grep

# Если не запущен — запустить:
dump1090 --raw --net --quiet &
```

### ❌ Ошибка: `Cannot connect to Ollama`

```bash
# Запустить Ollama
ollama serve &

# Подождать 10 секунд и проверить
curl -s http://localhost:11434/api/tags
```

### ❌ Ошибка: RTL-SDR не виден / `No supported RTLSDR devices found`

1. Убедись что донгл вставлен в USB
2. Проверь: `lsusb | grep -i RTL`
3. Установить драйвер: `sudo apt-get install rtl-sdr`
4. Добавить правило udev: `sudo rtl_test -t`

### ℹ️ Система работает, но самолётов нет

Это нормально, если:
- Донгл не подключён (демо-режим)
- В данный момент нет самолётов в зоне приёма
- Антенна не подключена к донглу

## Часть 10 — Что означает успешный запуск

### Признаки что всё работает ✅

1. **В терминале** — нет красных `ERROR` сообщений при старте
2. **Браузер** → `http://localhost:8080` — открывается дашборд с картой
3. **Дашборд** показывает:
   - Зелёный индикатор **WS** (WebSocket connected)
   - Индикатор **LLM** зелёный или жёлтый
   - Осциллограф отображает сигнал (даже без самолётов — шумовой уровень)
4. **API** `/health` возвращает `"status": "ok"`

### Что делать если система запустилась, но что-то не так

- Смотри в терминале — все ошибки выводятся там в реальном времени
- Ищи строки `ERROR` или `❌` — они говорят о конкретной проблеме
- Смотри папку `logs/` — там сохраняются логи работы системы

### Остановить систему

Нажми `Ctrl+C` в терминале — система корректно завершит работу.
