## 1. Что такое OPHIR 2.0?

**OPHIR 2.0 (кодовое название AEGIS-X)** — это веб-программа для мониторинга воздушного пространства.

Она принимает сигналы от самолётов по технологии **ADS-B** через SDR-приёмник (маленькое USB-радио) и показывает на карте, какие самолёты сейчас находятся в радиусе приёма.

**Простыми словами:**  
Подключаешь USB-радио к компьютеру → запускаешь OPHIR → открываешь браузер → видишь карту с самолётами в реальном времени.

## 2. Полный список возможностей

### 📡 Приём и отображение самолётов
- Подключается к программе **dump1090** (декодер ADS-B-сигналов), которая читает данные с SDR-приёмника
- Показывает самолёты на интерактивной карте (через Leaflet / OpenStreetMap)
- Обновляет позиции в реальном времени каждые 1–2 секунды через WebSocket
- Отображает: HEX-код (уникальный ID самолёта), позывной, высоту, скорость, курс, вертикальную скорость

### 🗂️ Фильтрация самолётов
- Кнопки фильтра: **ALL** (все), **GPS ✓** (с координатами), **SHADOW** (без GPS), **MIL** (военные)
- "Тени" (Shadows) — самолёты, которые слышны по радио, но не передают координаты GPS

### 📊 Статистика и рекорды
- Вкладка **RECORDS**: рекорды по максимальной высоте, максимальной скорости, лучшему сигналу, новые уникальные борта за сегодня
- Вкладка **STATS**: сводка — сколько самолётов видно, сколько передают GPS, средний RSSI, статус LLM и dump1090

### 📏 Расчёт расстояния
- Два метода расчёта дистанции до самолёта:
  1. **GPS** — по координатам самолёта (точно, если самолёт передаёт GPS)
  2. **Friis FSPL** — по уровню сигнала (RSSI), модель свободного пространства на частоте 1090 МГц (когда GPS нет)
- Определяет азимут (угол) и угол возвышения от точки наблюдателя до самолёта

### 🤖 Классификатор сигналов
- Автоматически определяет: гражданский самолёт, военный, неизвестный
- Анализирует HEX-префикс ICAO (например AE... — армия США) и позывной
- Ставит флаги: MILITARY_HEX_PREFIX, MILITARY_CALLSIGN, NO_POSITION, HIGH_SPEED, EXTREME_ALTITUDE

### 🚨 Детектор угроз и аномалий
- Следит за аномалиями в реальном времени:
  - Резкое падение высоты (более 5000 футов за одно обновление)
  - Резкое изменение скорости (более 150 узлов за одно обновление)
  - Скачок уровня сигнала RSSI (более 20 dBm — признак помех или спуфинга)
  - Отрицательная высота (ошибочные данные)
  - Экстремальная скорость (более 700 узлов)

### 🧠 ИИ-анализ через LLM (Ollama)
- При обнаружении подозрительного борта запрашивает у локальной AI-модели (Mistral через Ollama) краткую оценку угрозы
- Анализ выводится прямо в карточке самолёта и в нижней панели экрана
- LLM можно включить/выключить кнопкой на интерфейсе

### 📚 Машинное обучение (Learning Engine)
- Автоматически собирает данные от гражданских самолётов с GPS
- Строит локальную калибровочную модель RSSI→дистанция для твоей антенны и окружения
- После 10 наблюдений начинает давать уточнённые оценки расстояния

### 📺 Осциллограф сигналов
- Нижняя панель экрана: два канала реального времени
  - CH1 (синий) — уровень ADS-B сигнала (RSSI, dBm)
  - CH2 (фиолетовый) — уровень RF-шума
- История последних 60 секунд, обновляется каждую секунду

### 🗃️ База данных и архив
- Записывает все встреченные самолёты в SQLite базу данных
- Можно добавить неизвестный самолёт вручную через форму в интерфейсе
- Страница /archive — просмотр всей истории встреченных самолётов

### 🔧 Управление dump1090
- Кнопки Start / Stop / Restart для управления процессом dump1090 прямо из браузера

## 3. Как запустить проект

### Что нужно иметь

| Что | Зачем |
|-----|-------|
| Python 3.10 или новее | Язык программирования проекта |
| SDR-приёмник (RTL-SDR) | USB-радио для приёма самолётов |
| dump1090 (или dump1090-fa) | Программа-декодер ADS-B сигналов |
| Ollama + модель Mistral | Для AI-анализа (необязательно) |

### Шаг 1 — Установить зависимости

```bash
cd /папка/с/проектом
pip install -r requirements.txt
```

### Шаг 2 — Запустить dump1090 (если есть SDR)

```bash
dump1090-fa --net --quiet
# или
dump1090 --net --quiet
```

Если dump1090 не установлен или SDR нет — программа всё равно запустится, но данных о самолётах не будет.

### Шаг 3 — Запустить OPHIR

**Способ 1 (всё сразу, рекомендуется):**
```bash
python run.py
```
Это автоматически запустит dump1090 (если он есть) и FastAPI-сервер.

**Способ 2 (только сервер):**
```bash
python main.py
# или через uvicorn:
uvicorn main:app --host 0.0.0.0 --port 8080
```

**Способ 3 (скрипт-оболочка):**
```bash
./start.sh
```

### Шаг 4 — Открыть в браузере

После запуска открой в браузере:
```
http://localhost:8080         — главный дашборд
http://localhost:8080/archive — архив самолётов
http://localhost:8080/docs    — документация API (автогенерируется FastAPI)
```

## 5. Файлы данных и база данных

### Файлы данных в репозитории

| Файл | Что это |
|------|---------|
| `data/aircraft_archive.json` | Небольшой тестовый архив с 3 бортами (USA военный MOOSE68, канадский RJA132, эфиопский ETH431) — **пример данных** |
| `aircraft_metadata.db` | SQLite-база данных с метаданными самолётов |
| `db/ophir.db` | SQLite-база данных для хранения архива бортов и истории треков |

### База данных, которая создаётся при запуске

При первом запуске программа автоматически создаёт несколько SQLite-баз:

| База | Расположение | Содержимое |
|------|-------------|------------|
| Основная БД | `data/ophir_db/ophir.db` | Таблицы: самолёты, история треков, аномалии |
| Тренировочная БД | `db/signal_training.db` | Данные для калибровки RSSI (Learning Engine) |

### Таблицы основной базы данных

- **aircraft** — все встреченные борта: hex-код, позывной, тип, страна, координаты, высота, скорость, сигнал, флаг "тени"
- **track_history** — история позиций каждого борта (для воспроизведения трека)
- **anomalies** — зафиксированные аномалии и результат LLM-анализа

### Откуда берётся архив по умолчанию

По умолчанию используется файл `data/aircraft_archive.json`. Он содержит **тестовые данные** — 3 самолёта для проверки. В реальной работе данные поступают от SDR-приёмника через dump1090 и накапливаются в базе данных.

## 6. Модуль LLM — что он делает

### Что такое LLM?

**LLM** (Large Language Model, большая языковая модель) — это AI, который умеет понимать и генерировать текст. В OPHIR используется **Mistral** — открытая AI-модель, которая запускается **локально** на твоём компьютере через программу **Ollama**.

### Для чего LLM в OPHIR?

Когда система обнаруживает подозрительный или необычный самолёт, она отправляет его данные в AI и получает краткий текстовый анализ на естественном языке.

Пример запроса к AI:
```
Analyze this ADS-B anomaly:
Aircraft ICAO: AE1465
Anomaly Type: RSSI_SPIKE
Callsign: MOOSE68
Altitude: 15000 ft
Speed: 400 kt
RSSI: -62 dBm
Position: 31.5, 34.8

Provide brief security assessment (2-3 sentences).
```

Пример ответа AI:
> "MOOSE68 appears to be a US military transport aircraft based on its ICAO hex prefix (AE). The sudden RSSI spike may indicate the aircraft changed its flight path relative to the receiver. No immediate threat indicators beyond the signal anomaly."

### Что умеет LLM-модуль

| Функция | Описание |
|---------|---------|
| Анализ аномалий | Оценивает каждую обнаруженную аномалию (скачок сигнала, падение высоты, скоростная аномалия) |
| Анализ по запросу | Можно нажать на самолёт → открыть карточку → увидеть AI-оценку прямо там |
| Проверка соединения | При старте проверяет, доступен ли Ollama на localhost:11434 |
| Включение/выключение | Можно выключить LLM кнопкой — тогда анализ не будет запрашиваться |

### Сценарии работы LLM

**Сценарий 1 — Ollama запущен и модель загружена:**
- LLM статус в интерфейсе: `LLM ● mistral`
- При клике на самолёт → в нижнем блоке появится текстовый анализ
- Ответ появляется через 3–30 секунд

**Сценарий 2 — Ollama не запущен:**
- LLM статус: `LLM ○ disabled`
- Вместо анализа показывается: `LLM analysis is currently disabled.`
- Всё остальное работает нормально

**Сценарий 3 — LLM выключен пользователем:**
- Кнопка "Toggle LLM" выключила анализ
- Вместо анализа: `LLM analysis is currently disabled.`

### Технические параметры LLM

| Параметр | Значение |
|---------|---------|
| Адрес Ollama | `http://localhost:11434` |
| Модель | `mistral:latest` |
| Таймаут ответа | 60 секунд |
| Включён по умолчанию | Да |

## 7. Интерфейс — кнопки и параметры пользователя

### Главный дашборд (dashboard.html)

#### Верхняя панель управления (Top Bar)

```
🛰 OPHIR 2.0 | [dump1090: OK] [▶ Start] [■ Stop] [↺ Restart] | [🏠 Garage] [✈ Air] | Gain [━━━━━] 45 | [LLM: OK] [🤖 Toggle LLM] |   0 aircraft
```

| Кнопка / Элемент | Что делает |
|-----------------|-----------|
| **▶ Start** (зелёная) | Запустить dump1090 (процесс декодирования ADS-B) |
| **■ Stop** (красная) | Остановить dump1090 |
| **↺ Restart** | Перезапустить dump1090 |
| **🏠 Garage** | Профиль антенны "Гараж" (закрытое помещение): усиление 35 dB, порог -75 dBm |
| **✈ Air** (активна по умолчанию) | Профиль антенны "Воздух" (открытое место): усиление 45 dB, порог -90 dBm |
| **Ползунок Gain** | Регулировка усиления SDR-приёмника от -5 до +45 dB. Больше = больше дальность, но больше шума |
| **🤖 Toggle LLM** | Включить или выключить AI-анализ (LLM Mistral) |
| **Индикатор dump1090** | Зелёный кружок = dump1090 работает, красный = не запущен |
| **Индикатор LLM** | Зелёный = Ollama подключён, серый = недоступен |

#### Правая панель

| Элемент | Описание |
|---------|---------|
| **Signal Info** | Карточка выбранного самолёта: тип, позывной, страна, RSSI, дистанция, высота, скорость, курс, ICAO-код |
| **Список самолётов** | Прокручиваемый список всех видимых бортов с метками CIV / MIL / ANM / UNK |

#### Нижняя полоса

| Элемент | Описание |
|---------|---------|
| **Осциллограф CH1** | Синяя волна — уровень ADS-B сигнала (dBm) последние 60 сек |
| **Осциллограф CH2** | Фиолетовая волна — уровень RF шума (dBm) последние 60 сек |
| **LLM Analysis** | Последний текст от AI-анализатора |

## 8. Контроллеры — API-команды программы

Все команды можно открыть в браузере через `http://localhost:8080/docs`.

### 🛩️ Самолёты (Aircraft)

| Метод | Адрес | Что делает |
|-------|-------|-----------|
| GET | `/aircraft` | Список всех самолётов онлайн прямо сейчас |
| GET | `/api/v1/live/aircraft` | Живые данные + метка времени |
| GET | `/api/v1/archive/aircraft` | Все самолёты из архивной базы данных |
| GET | `/api/v1/aircraft/{hex}/details` | Полная карточка самолёта (живые данные + БД) |
| GET | `/api/v1/aircraft/{hex}/position` | Только позиция (лёгкий запрос) |
| GET | `/api/v1/aircraft/{hex}/analysis` | Классификация + LLM анализ конкретного борта |
| GET | `/api/v1/aircraft/{hex}/distance` | Расстояние и азимут до самолёта |
| POST | `/api/v1/aircraft/unknown/add` | Добавить неизвестный самолёт в базу вручную |

### 📡 Сигнал и шум

| Метод | Адрес | Что делает |
|-------|-------|-----------|
| GET | `/noise` | Текущий тип сигнала, уровень шума, история |
| GET | `/raw` | Последние сырые сообщения от dump1090 |
| GET | `/events` | Последние 50 событий (новые борты, сигналы) |
| GET | `/api/v1/oscilloscope/data` | Снимок данных осциллографа (CH1 + CH2) |

### 🚨 Угрозы и аномалии

| Метод | Адрес | Что делает |
|-------|-------|-----------|

## 10. Словарь терминов для новичков

| Термин | Простое объяснение |
|--------|-------------------|
| **ADS-B** | Технология, при которой самолёт автоматически передаёт по радио: своё местоположение GPS, высоту, скорость, позывной. Принимается на частоте 1090 МГц |
| **SDR** (Software Defined Radio) | Маленькое USB-радио (размером с флешку), которое принимает широкий диапазон частот. Подключается к компьютеру, и компьютер сам обрабатывает сигнал |
| **dump1090** | Программа, которая слушает SDR и декодирует ADS-B сигналы от самолётов в понятный текст (позиции, скорости и т.д.) |
| **RSSI** | Received Signal Strength Indicator — уровень мощности принятого сигнала. Измеряется в dBm. Чем меньше (ближе к 0), тем сильнее сигнал. -60 dBm хороший, -90 dBm слабый |
| **ICAO HEX** | Уникальный 6-значный шестнадцатеричный код самолёта. Как VIN-номер для машины. Пример: AE1465 |
| **Callsign / Позывной** | Буквенно-цифровой код борта в конкретном полёте. Пример: EL123 (El Al рейс 123) |
| **Shadow / Тень** | Самолёт, который слышен по радио, но не передаёт GPS-координаты. Виден в таблице, но не на карте |
| **LLM** | Large Language Model — большая языковая модель AI. В OPHIR используется Mistral через Ollama для анализа аномалий |
| **Ollama** | Программа, которая запускает AI-модели (как Mistral) на твоём компьютере локально, без интернета |
| **FastAPI** | Python-фреймворк для создания веб-API. Именно на нём написан сервер OPHIR |
| **WebSocket** | Технология постоянного соединения браузера с сервером для получения данных в реальном времени (без обновления страницы) |
| **dBm** | Децибел-милливатт — единица измерения мощности сигнала. -60 dBm > -90 dBm (значит сигнал сильнее) |
| **Friis FSPL** | Формула расчёта затухания радиосигнала в открытом пространстве. Используется для оценки расстояния до самолёта по уровню RSSI, когда GPS нет |
| **Pull Request (PR)** | Запрос на слияние изменений кода. Если ты изменил файлы в своей ветке и хочешь добавить их в основную (main) — ты создаёшь PR. Другие могут проверить изменения |
| **Conflict / Конфликт** | Когда два изменения касаются одной строки файла, Git не знает, какое оставить. "Incoming" = изменение из другой ветки, "Current" = твоё изменение |
| **Branch / Ветка** | Отдельная копия кода для работы над новой функцией. Не мешает основной версии (main) |
