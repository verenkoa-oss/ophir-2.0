## 1. Что нужно для работы

| Компонент | Зачем нужен | Обязательно? |
|---|---|---|
| **Python 3.8+** | Запускает сам OPHIR | ✅ Да |
| **Ollama + Mistral** | AI-анализ самолётов (LLM) | ⚠️ Желательно |
| **dump1090** | Принимает сигналы с RTL-SDR антенны | ⚠️ Нужен для реальных данных |
| **RTL-SDR донгл** | USB-антенна для приёма ADS-B сигналов | ⚠️ Нужен для реальных данных |
| **Git** | Скачать код OPHIR с GitHub | ✅ Да (или скачать ZIP) |

> **Без RTL-SDR и dump1090 система работает в демо-режиме** — данные о самолётах будут
> смоделированы. Интерфейс, LLM, карта — всё работает.

## Часть 1 — Очистка старой версии

### Если ты уже устанавливал OPHIR раньше — сначала удали его

#### На Linux / macOS (в Терминале):

```bash
# Остановить все процессы OPHIR, если они запущены
pkill -f "python3 run.py" 2>/dev/null || true
pkill -f "uvicorn" 2>/dev/null || true
pkill -f "dump1090" 2>/dev/null || true

# Перейти в папку выше и удалить старую папку
cd ~
rm -rf ophir-2.0
```

#### На Windows (в PowerShell или CMD):

```powershell
# Остановить процессы Python если запущены
taskkill /IM python.exe /F 2>NUL

# Удалить папку со старой версией
# (замени C:\Users\ТвоёИмя\ophir-2.0 на реальный путь)
rmdir /S /Q C:\Users\%USERNAME%\ophir-2.0
```

#### Дополнительно — очистить старую виртуальную среду Python

```bash
# Linux / macOS — если была создана venv
rm -rf ~/ophir-2.0/venv
rm -rf ~/.venv/ophir
```

#### Очистить базу данных (если нужно начать с нуля)

```bash
# Linux / macOS
rm -f ~/ophir-2.0/db/ophir.db
rm -f ~/ophir-2.0/aircraft_metadata.db
rm -rf ~/ophir-2.0/data/ophir_db/
```

> ✅ После этого старая версия полностью удалена. Можно устанавливать новую.

## Часть 2 — Установка Python

### Проверить, установлен ли Python:

```bash
python3 --version
```

Если видишь что-то вроде `Python 3.11.5` — Python установлен, переходи к Части 3.

### Если Python не установлен:

#### Linux (Ubuntu / Debian):
```bash
sudo apt update
sudo apt install python3 python3-pip python3-venv -y
```

#### macOS:
```bash
# Через официальный сайт: https://www.python.org/downloads/
# Или через Homebrew:
brew install python3
```

#### Windows:
1. Открой сайт: **https://www.python.org/downloads/**
2. Нажми **"Download Python 3.x.x"**
3. Установи, и **обязательно поставь галочку "Add Python to PATH"** при установке
4. После установки открой PowerShell и проверь: `python --version`

## Часть 3 — Установка Ollama и модели Mistral

> Ollama — это программа, которая запускает AI-модели (LLM) **локально на твоём компьютере**.  
> OPHIR использует модель **Mistral** для анализа аномалий в воздушном пространстве.

### Установка Ollama:

#### Linux:
```bash
curl -fsSL https://ollama.ai/install.sh | sh
```

#### macOS:
1. Открой сайт **https://ollama.ai**
2. Нажми **"Download"** и установи `.dmg` файл
3. Или через Homebrew: `brew install ollama`

#### Windows:
1. Открой сайт **https://ollama.ai**
2. Нажми **"Download for Windows"**
3. Установи `.exe` файл как обычную программу

### Запустить Ollama:

```bash
# Linux / macOS — в отдельном терминале:
ollama serve
```

На Windows Ollama запускается автоматически как системная служба после установки.

### Скачать модель Mistral:

```bash
# Выполнить эту команду (загрузка ~4 ГБ, нужен интернет):
ollama pull mistral:latest
```

> ⏳ Скачивание займёт несколько минут — зависит от скорости интернета.

### Проверить, что Ollama работает:

```bash
curl http://localhost:11434/api/tags
```

Если видишь JSON с `"mistral"` — всё работает. ✅

## Часть 4 — Установка dump1090 (опционально)

> dump1090 нужен **только если у тебя есть RTL-SDR USB-антенна**.  
> Без неё система запустится в демо-режиме — пропусти эту часть.

#### Linux (Ubuntu / Debian):
```bash
sudo apt update
sudo apt install dump1090-fa -y
```

#### Запустить dump1090:
```bash
# В отдельном терминале:
dump1090-fa --raw --net --quiet
```

> После этого dump1090 начнёт слушать порт **30001** и передавать данные в OPHIR.

## Часть 5 — Скачивание и установка OPHIR 2.0

### Шаг 1: Скачать код OPHIR с GitHub

```bash
# Перейти в домашнюю папку
cd ~

# Скачать репозиторий
git clone https://github.com/verenkoa-oss/ophir-2.0.git

# Зайти в папку
cd ophir-2.0
```

> Если `git` не установлен:
> - Linux: `sudo apt install git -y`
> - macOS: `brew install git`
> - Windows: скачай с **https://git-scm.com/download/win**
>
> Альтернатива без git: на GitHub нажми **"Code" → "Download ZIP"**, распакуй архив.

---

### Шаг 2: Создать виртуальную среду Python (рекомендуется)

Виртуальная среда изолирует все пакеты OPHIR от остальной системы.

```bash
# Находясь в папке ophir-2.0:
python3 -m venv venv
```

Активировать виртуальную среду:

```bash
# Linux / macOS:
source venv/bin/activate

# Windows (PowerShell):
.\venv\Scripts\Activate.ps1

# Windows (CMD):
venv\Scripts\activate.bat
```

> После активации в начале строки терминала появится `(venv)` — это нормально. ✅

---

### Шаг 3: Установить зависимости Python

```bash
pip3 install -r requirements.txt
```

> Это установит: FastAPI, Uvicorn, SQLAlchemy, PyModeS и другие пакеты.  
> Процесс займёт 1-3 минуты.

Проверить что всё установилось:
```bash
pip3 list | grep -E "fastapi|uvicorn|sqlalchemy"
```

## Часть 7 — Что видно на экране и какие кнопки есть

### Главный экран (index.html)

```
┌─────────────────────────────────────────────────────────────┐
│ OPHIR 2.0 — Signal Intelligence System       [ON/OFF] [GAIN]│
├────────────────────────────────────┬────────────────────────┤
│                                    │  Вкладки:               │
│          КАРТА (Leaflet)           │  [AIRCRAFT] [THREATS]  │
│                                    │  [LEARNING] [ARCHIVE]  │
│   🔵 Самолёты на карте             │                         │
│   🔴 Угрозы / аномалии             │  Таблица самолётов:    │
│   📍 Позиция наблюдателя           │  Hex | Call | Alt | km │
│                                    │  ─────────────────────  │
│                                    │  A1B2C3 UAL123 35000ft │
│                                    │  ...                    │
├────────────────────────────────────┴────────────────────────┤
│ ОСЦИЛЛОГРАФ: [RSSI ──────] [NOISE ──────]                   │
└─────────────────────────────────────────────────────────────┘
```

### Описание элементов:

| Элемент | Что делает |
|---|---|
| **Карта** | Показывает самолёты в реальном времени. Синие точки = обычные, красные = угрозы |
| **Вкладка AIRCRAFT** | Таблица всех обнаруженных самолётов: позывной, высота, скорость, расстояние, RSSI |
| **Вкладка THREATS** | Список обнаруженных аномалий и угроз с уровнем опасности |
| **Вкладка LEARNING** | Статистика ML-движка: сколько самолётов изучено, паттернов найдено |
| **Вкладка ARCHIVE** | История прошлых полётов из базы данных |
| **Осциллограф** | Два графика: RSSI (мощность сигнала) и Noise (уровень шума) за последние 60 сек |
| **Кнопка ON/OFF** | Включить / выключить систему мониторинга |
| **Ползунок GAIN** | Регулировка усиления антенны (-5 до +45 dB) |
| **Noise Threshold** | Порог шума — фильтрует слабые/ложные сигналы |

### API и документация:

| Адрес | Что это |
|---|---|
| `http://localhost:8080/` | Главный дашборд |
| `http://localhost:8080/docs` | Интерактивная документация всех API-эндпоинтов |
| `http://localhost:8080/health` | Проверка состояния системы |
| `http://localhost:8080/aircraft` | JSON со всеми активными самолётами |
| `http://localhost:8080/threat/current` | Текущая оценка угроз |

## Часть 9 — Типичные ошибки и как их исправить

### ❌ `ModuleNotFoundError: No module named 'fastapi'`

**Причина:** Зависимости не установлены, или активирована неправильная среда.

```bash
# Активируй venv и установи заново:
source venv/bin/activate    # Linux/macOS
pip3 install -r requirements.txt
```

---

### ❌ `Connection refused` на порту 11434 (Ollama)

**Причина:** Ollama не запущена.

```bash
# Запусти Ollama в отдельном терминале:
ollama serve

# Или проверь статус:
curl http://localhost:11434/api/tags
```

---

### ❌ `Connection refused` на порту 30001 (dump1090)

**Причина:** dump1090 не запущен. Это нормально если нет RTL-SDR антенны.

Система переключится в демо-режим автоматически.

Если RTL-SDR есть:
```bash
# Запусти dump1090 в отдельном терминале:
dump1090-fa --raw --net --quiet
```

---

### ❌ Браузер не открывает `http://localhost:8080`

**Причина:** Сервер ещё не запустился или завершился с ошибкой.

Проверь терминал — там должно быть сообщение `Uvicorn running on http://0.0.0.0:8080`.

```bash
# Проверить, занят ли порт:
lsof -i :8080       # Linux/macOS
netstat -an | findstr 8080   # Windows
```

---

### ❌ Медленный запуск Ollama / LLM-анализ зависает

**Причина:** Модель Mistral требует ~4 ГБ RAM. На слабых машинах может тормозить.

```bash
# Проверить загруженные модели:
ollama list

# Если нужно, можно отключить LLM в config.py:
# Найди строку: ENABLE_LLM_ANALYSIS = True
# Измени на:    ENABLE_LLM_ANALYSIS = False
```

---

### ❌ `Permission denied` при запуске start.sh

```bash
chmod +x start.sh
bash start.sh
```

```bash
# === ОЧИСТКА ===
rm -rf ~/ophir-2.0          # Удалить папку

```
